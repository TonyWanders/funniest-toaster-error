A program that writes the funniest error message a kitchen toaster would
show its owner to `/output/entry.txt`, for the make.fun competition
[The Funniest Toaster Error Message](https://make.fun/bounty/u-eager-stork-81-9647-the-funniest-toaster-error-436406cd).

Run it with Python 3:

```
python3 main.py
```

It writes the entry below to `/output/entry.txt` (or to the path given as
the first argument, or `$OUTPUT_PATH`) and prints it. No network, no clock,
no randomness. The entry is 81 characters, inside the 1 to 120 gate.

## The entry

```
ERROR E04: I toasted it perfectly. You left it in me for an hour. This is on you.
```
